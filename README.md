# NeoLight 


## Description
NeoLight is an IoT-based smart study lamp that detects motion using a PIR sensor and automatically turns ON/OFF the light. It also displays status on LCD and uses a buzzer for alerts.
This project focuses on Power Saving.


Simulation Link: https://wokwi.com/projects/464519388328526849

##  Features
- Motion detection using PIR sensor
- Automatic light control
- LCD display for status
- Buzzer alert system
- Energy saving

##  Technologies Used
- ESP32 / Arduino
- Embedded C
- Wokwi Simulation

##  Components
- PIR Sensor
- LED
- Buzzer
- LCD (I2C)

##  Working
1. PIR detects motion
2. LED turns ON
3. LCD shows "Motion Detected"
4. After no motion, system turns OFF automatically
